# 自带封面系统

目标是让同一账号的封面有稳定识别度，同时每一期的主视觉都能解释选题。

## 输出

- 横版：1920×1080，适合 YouTube、B站和横版展示；
- 竖版：1080×1920，适合抖音等竖屏平台；
- 两种比例分别构图和排版，不拉伸，也不把横版直接裁成竖版。

## 制作流程

### 1. 提炼封面信息

从成片提炼：

- 一个移动端能快速读完的主标题，尽量控制在 14–18 个汉字；
- 一个可选短副标题，只补充主标题没有表达的机制或收益；
- 一个主视觉，它应该让观众不读标题也能大概猜到视频在讲什么。

不要自动加入期数、日期、栏目名、多少秒看懂、随机英文和无关标签。

### 2. 生成无字主视觉

在 Codex 中使用原生 `imagegen`，分别生成横版和竖版底图。其他 Agent 使用自己的原生图片生成能力；没有时，先完成图像生成接口配置。提示词需要说明：

- 主题对象或真实场景；
- 对象怎样表现本期的机制、过程或结果；
- 标题区域和主视觉区域；
- 与成片一致的主色和高亮色；
- 禁止可读文字、Logo、水印和乱码。

图片模型只负责场景、物体、拼贴、纹理、光影和空间层次，不负责关键中文。

### 3. 确定性排版

使用 HyperFrames、HTML/CSS 或 SVG 把中文标题覆盖到底图上。优先使用正常字宽的中文黑体，不对标题做横向拉伸。

- 横版通常采用左文右图或右文左图；标题区约占 40%，主视觉约占 60%。
- 竖版标题通常位于上方约 35%–42%，主视觉位于下方约 58%–65%。
- 标题放不下时，先改写或自然换行，再调整字号；不要压窄字体。
- 保持一个主标题、一个主视觉和少量必要标注，避免把封面堆成信息墙。

这些是常用起点，不是固定模板。标题层级和留白可以稳定，主视觉必须跟随选题变化。

## 配色

- 先确定一个主色、一个正文色和一个小面积高亮色；
- 暗色、亮色都可以，文字必须与背景有稳定对比；
- 工具、文档和效率主题可优先使用暖白、深蓝、蓝绿与少量黄色或橙色；
- 真实视频感较强或技术密度较高的主题可使用深蓝、炭黑和明亮高亮色；
- 不同时使用多组高饱和颜色，也不要让红、蓝、黑大面积互相抢夺。

## 主视觉

优先选择一个具体对象、一个真实场景或一个可见过程，例如：被整理的会议记录、不断补齐的行动清单、连接起来的工具节点、从输入流向成片的生产线。

人物可以出现，但必须正在完成与主题直接相关的动作。不要默认生成一张惊讶、沉思或指向标题的陌生 AI 人像。

## 缩略图检查

输出前至少检查：

- 竖版缩小到约 270×480 后，主标题是否仍能快速读出；
- 横版缩小到约 480×270 后，标题是否完整；
- 是否只有一个清楚的视觉中心；
- 主视觉是否直接对应视频内容；
- 中文是否逐字正确，有没有拉伸、异常字距、断词或裁切；
- 是否出现乱码、随机英文、假日期、期数或无关装饰；
- 横竖版是否像同一条视频，但都适合自己的比例。

任一项不通过，就先修改封面，再进入发布包。
