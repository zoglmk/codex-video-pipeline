# 字幕契约

## 正式字幕的来源

必须使用成片最终旁白文件进行声学转写或强制对齐。以下来源不能用于发布：

- 按字符数平均分配时间；
- 用预估语速切句；
- 先对齐旧音频，再替换新旁白；
- 只整体平移字幕轨掩盖局部错位；
- `estimated`、`unknown` 或没有提供方记录的时间轴。

## JSON 格式

~~~json
{
  "items": [
    {"text": "你看到的是一份很乱的会议记录", "start": 0.08, "end": 2.76},
    {"text": "AI先把决定和行动项分开", "start": 2.84, "end": 5.41}
  ]
}
~~~

时间单位为秒，按开始时间递增，`end` 必须大于 `start`。

## 显示规则

- 使用完整短句，一般约 10–22 个汉字；
- 整句稳定显示，只做轻微淡入淡出；
- 中文词语之间不加多余空格；
- 句末标点可在显示层去掉，内部标点保留；
- 英文 Skill、插件、产品名和带连字符标识符视为不可拆单元；宁可一条略长或同框换行，也不要拆到前后两条；
- 正式发布前抽查每段句首、句中和句尾。

## 凭据

`caption_gate.py record` 会记录音频和字幕文件的 SHA-256。任何一个文件在对齐后发生变化，`verify` 都会失败，需要重新对齐。

新凭据会优先把音频和字幕路径保存为相对于凭据文件的位置。只要整个项目目录一起移动，macOS、Windows 和 Linux 都能继续验证。旧版凭据中的绝对路径仍可读取，但换电脑或移动项目后需要重新执行 `record`。
